# 🚀 ریله‌ی MTProto تلگرام روی Cloudflare Worker

یک کد تک‌فایلی برای **Cloudflare Workers** که مانند پنل‌های رایج (BPB / Nova) یک
سرور عبوردهی روی شبکه‌ی کلودفلر می‌سازد — این ورکر ترافیک پراکسی تلگرام را از داخل
شبکه‌ی کلودفلر به **دیتاسنترهای رسمی تلگرام** تونل می‌کند و چون IPهای کلودفلر قابل
فیلترشدن نیستند، پایدار و رایگان است.

> **کاربر وی‌پی‌ان نمی‌شوید!** این پروژه فقط و فقط برای عبور ترافیک **تلگرام** است
> (مقصد تونل به رنج‌های IP متعلق به تلگرام محدود شده است). برای عبور ترافیک سایر
> اپلیکیشن‌ها باید از VLESS/Trojan (مثل پنل BPB) استفاده کنید.

---

## 🧠 اول یک نکته‌ی فنی مهم

ورکر کلودفلر فقط می‌تواند ورودی **HTTP / WebSocket** بگیرد و سوکت TCP خامِ ورودی
ندارد. پروتکل پراکسی داخلی تلگرام (MTProto) روی **TCP خام** کار می‌کند؛ بنابراین
یک ورکر به‌تنهایی نمی‌تواند مستقیم پراکسی MTProto باشد.

راه‌حلی که در اکوسیستم فعلی (پروژه‌های `tg-ws-proxy` و `TG-Proxy`) استفاده می‌شود:

```
تلگرام موبایل/دسکتاپ
      │  MTProto (TCP)
      ▼
اپ پراکسی محلی  ◄── روی گوشی/کامپیوترِ خودتان اجرا می‌شود (127.0.0.1:1443)
      │  WebSocket امن (WSS / پورت 443)
      ▼
ورکر کلودفلر شما  ◄── کد همین مخزن (رایگان، روی طرح Free)
      │  TCP خام پورت 443
      ▼
دیتاسنترهای تلگرام (DC1..DC5)
```

یعنی: **ورکر = تونل رایگان روی شبکه‌ی کلودفلر** و **اپ محلی = پروتکل MTProto**.
رمز (Secret) توسط همان اپ محلی ساخته می‌شود و روی دستگاهِ شما می‌ماند.

## 📦 نصب روی Cloudflare Workers (۳ روش)

### روش ۱: بدون هیچ ابزاری — از داشبورد مرورگر

1. وارد [dash.cloudflare.com](https://dash.cloudflare.com) شوید ← منوی
   **Compute (Workers & Pages)** ← **Create application** ← **Start with Hello World** ← **Deploy**.
2. روی **Edit code** کلیک کنید و کل محتوای فایل [`worker.js`](./worker.js) را جایگزین کنید.
3. **Deploy** را بزنید و دامنه‌ی ورکر را کپی کنید، مثلاً:
   `tg-mtproto-relay.YOUR-ACCOUNT.workers.dev`
4. همان دامنه را در اپ پراکسی محلی (پایین) وارد کنید.

### روش ۲: با Wrangler

```bash
npm install -g wrangler
wrangler login
wrangler deploy
```

### روش ۳: دکمه‌ی Deploy

این مخزن را Fork کنید و با Wrangler CI یا دکمه‌ی «Deploy to Cloudflare» مستقرش کنید.

بعد از استقرار، با باز کردن آدرس ورکر در مرورگر باید صفحه‌ی راهنمای فارسی را ببینید.
بررسی سلامت: `https://YOUR-WORKER.workers.dev/health`

## 📱 اتصال تلگرام — کدام اپ را نصب کنم؟

### الف) کامپیوتر (ویندوز / لینوکس / مک): tg-ws-proxy

1. نسخه‌ی آخر را از
   [Flowseal/tg-ws-proxy](https://github.com/Flowseal/tg-ws-proxy/releases)
   (یا نسخه‌ی لینوکس/سرویس: [tg-ws-proxy-rs](https://github.com/valnesfjord/tg-ws-proxy-rs))
   دانلود و اجرا کنید.
2. در تنظیمات برنامه، بخش **Cloudflare Worker**، دامنه‌ی ورکر خود را وارد کنید
   (یا هنگام اجرا):

   ```bash
   tg-ws-proxy --cf-worker-domain tg-mtproto-relay.YOUR-ACCOUNT.workers.dev
   ```

3. در تلگرام: **Settings ← Advanced ← Connection type ← Add proxy ← MTProto**

   | تنظیم | مقدار |
   |---|---|
   | Server | `127.0.0.1` |
   | Port | `1443` |
   | Secret | مقداری که برنامه نمایش می‌دهد |

### ب) اندروید: TG Proxy

1. اپ [Dushnyj/TG-Proxy](https://github.com/Dushnyj/TG-Proxy/releases) را نصب کنید.
2. در بخش مسیرها، گزینه‌ی **Cloudflare Worker** را انتخاب و دامنه‌ی ورکر را وارد کنید.
3. اپ به‌صورت خودکار لینک `tg://proxy` می‌سازد؛ روی «افزودن پروکسی در تلگرام» بزنید.

### ج) تلگرام وب در مرورگر (Telegram Web)

این ورکر یک پل WebSocket هم دارد: در تنظیمات پروکسی کلاینت وب
(مثل Telegram Web A MOD) دامنه‌ی ورکر را به‌عنوان Proxy Domain وارد کنید. اتصال به‌شکل
`wss://YOUR-WORKER.workers.dev/venus.web.telegram.org/apiws` برقرار می‌شود.

## 🔌 مسیرهای ورکر

| مسیر | کاربرد |
|---|---|
| `GET /` | صفحه‌ی راهنمای فارسی |
| `GET /health` | وضعیت سرویس و اطلاعات DCها (JSON) |
| `WSS /apiws?dst=<IP-DC>&port=443` | تونل TCP — سازگار با tg-ws-proxy / TG-Proxy |
| `WSS /<host>.web.telegram.org/apiws` | پل WebSocket برای تلگرام وب |

IPهای دیتاسنترها (مقصد مجاز تونل):

| DC | موقعیت | IP |
|---|---|---|
| 1 | میامی (آمریکا) | `149.154.175.50` |
| 2 | آمستردام (هلند) | `149.154.167.50` |
| 3 | میامی (آمریکا) | `149.154.175.100` |
| 4 | آمستردام (هلند) | `149.154.167.91` |
| 5 | سنگاپور | `91.108.56.130` |

> توصیه‌ی پروژه‌های بالادست برای پایداری رسانه (عکس/ویدئو) در حساب‌های بدون پرمیوم:
> در بخش `DC -> IP` فقط `4:149.154.167.220` را نگه دارید.

## 🔒 نکات امنیتی

- مقصد تونل با **فهرست سفید** فقط به رنج‌های IP متعلق به تلگرام (`AS62041`) محدود است؛
  هیچ ترافیک دیگری (اسکنر، پروکسی عمومی، دسترسی به شبکه‌ی داخلی) از ورکر شما عبور نمی‌کند.
- ورکر هیچ رمز/سِکرتی ندارد — رمز MTProto بین تلگرام و اپِ محلی شماست.
- هیچ داده‌ای در ورکر ذخیره یا ثبت (log) نمی‌شود؛ صرفاً بایت‌ها عبور می‌کنند.
- برای بستن حالت «پل تلگرام وب»، متغیر محیطی `ALLOW_WS_BRIDGE = "0"` را ست کنید.

## ❓ پرسش‌های پرتکرار

**آیا فقط با خود ورکر و بدون اپ محلی هم می‌شود؟**
خیر. تلگرام رسمی فقط پراکسی MTProto روی TCP می‌فهمد و ورکر سوکت TCP ورودی ندارد؛
اپ محلیِ روی دستگاه، این پروتکل را به WebSocket تبدیل می‌کند.

**روی طرح رایگان Cloudflare کار می‌کند؟**
بله — اتصال TCP خروجی (`cloudflare:sockets`) روی طرح رایگان هم در دسترس است.
برای مصرف سنگین می‌توانید به Workers Paid (۵ دلار/ماه) ارتقا دهید.

**فرق این با پنل BPB چیست؟**
پنل‌های BPB/Nova پراکسی همه‌منظوره (VLESS/Trojan برای کل ترافیک دستگاه) می‌دهند؛
این پروژه مختصِ پراکسی داخلی تلگرام است و با اپ‌های MTProto سازگار است.
